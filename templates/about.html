About RouteRX

What is RouteRX?

RouteRX is a web-based route optimization tool designed for healthcare organizations conducting outreach programs in underserved communities. The application uses ZIP-level facility scarcity to derive local vulnerability scores and identify ZIP codes inside a target county and route a mobile unit between public parking locations.

How It Works

  1. Data Collection: Facility data is aggregated by ZIP code and used to build a local vulnerability proxy
  2. Selection: ZIP codes are ranked by derived vulnerability, with optional geographic clustering before the final ZIPs are chosen
  3. Optimization: Routes are optimized using nearest-neighbor and 2-opt algorithms
  4. Visualization: Results displayed on interactive maps with detailed statistics

Social Vulnerability Index (SVI)

The SVI uses 16 US census variables to identify communities that may need support before, during, or after disasters. It includes factors such as:

  • Socioeconomic status (poverty, unemployment, income)
  • Household composition & disability
  • Minority status & language
  • Housing type & transportation

Technical Stack

  • Backend: Python, Flask, Pandas, OSMnx
  • Frontend: HTML5, CSS3, JavaScript (Vanilla)
  • Mapping: Leaflet.js, Folium
  • Data: CDC SVI and OpenStreetMap

Usage Tips

  • Use full state names (e.g., "Massachusetts" not "MA")
  • County is required because ZIP selection happens inside one county at a time
  • Start with 10-15 stops for optimal performance
  • Use Haversine for quick estimates and OSM for road-network distances
  • Use clustering when you want one selected ZIP from each geographic region instead of simply taking the top vulnerable ZIPs overall

Data Sources

  • CDC/ATSDR Social Vulnerability Index
  • OpenStreetMap
